# Wwise-Tools
Scripts, Plugins, and other misc tools for Audiokinetic Wwise

## Contents
Bounce Layers
- a WAAPI/Python tool to flatten a multi-layer Wwise container (a Blend container holding several Random containers) into a single baked Random container of N variations, by capturing the container's live output through the Wwise Recorder plugin. Supports looping source. Optionally disables source containers.
